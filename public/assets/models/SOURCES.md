# Model marks

Marks distributed by @lobehub/icons-static-svg 1.95.0 (MIT; see LICENSE-lobe-icons). Existing supplied marks retained. Provider/series names are mapped in src/model-brand.js. Kimi color mark uses a near-black foreground instead of the package's white foreground for the site's light surfaces; its blue accent and path geometry are unchanged. Unidentified providers retain an explicit generic fallback. No substitute brand is invented.
